# Windows Terminal

## Keyboard Shortcuts

This is a subset of what's on: https://howtoedge.com/windows-terminal-shortcut-keys/

| Command                         | Description                 |
|---------------------------------|-----------------------------|
| `<Ctrl> + <Shift> + T`          | Open New Tab                |
| `<Ctrl> + <Shift> + R`          | *Rename Tab                 |
| `<Ctrl> + <Alt> + Number (1-9)` | Switch between Tab 1 to 9   |
| `<Ctrl> + <Tab>`                | Switch to the Next tab      |
| `<Ctrl> + <Shift> + <Tab>`      | Go back to the previous tab |

\* Rename Tab shortcut may not be present by default, but you can add it by 
going into Settings -> Actions
