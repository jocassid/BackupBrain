# `mail`

## Handy commands

| Command  | Description                                     |
|----------|-------------------------------------------------|
| `d 1-10` | deletes messages 1-10                           |
| `d *`    | deletes all messages   -                        |
| `q`      | saves changes (i.e. messages deleted) and exits |
| `x`      | exits w/out saving changes                      |
